gi# Wildcat Training Planner User Manual

## Open Application
When the application is opened, the Dashboard will appear.  This is the home page from which all activity and information can be found.  A menu is displayed on the left side of the window pane displayiing all of the features of the applicaton.

## Menu

The left side Menu will display all of the functions available as follows:
Dashboard (Home Screen)
Development Library 
    - A comprehensive list of drills created by the coach and organized by development block
            When selected, information includes number of sets, length of work and rest focus and directions
Practice Builder
    - Where insert the drills created by the coach into the planner
Open Practice
    - Saved practices can be uploaded to the planeer (Shrtcut - Ctrl+o)
New Practice
    - create a new practice session (Shortcut - Ctrl+n)
Duplicate Practice 
    - create a duplicate of the current practice loading in the "Practice Builder"
Administration 
    - Configure the planner, create new Drills and other tools associated with administration

## Development Library
Select this button form the left menu to view the "Devwelopment Blocks" as displayed in the center panel of the resulting page.
    - Each development block as created in the configuration, will contain detailed information about each drill contained within that block if selected
        - Select any of the drills and complete information will be dislplayed in the right panel such as number of sets, work time of the drill per set, time the drill should be determined.  The coach must create these drills and popuate each field.  Data is optional for any of the drill fields.

## Creating a new practice session

Select the "Practice Builder" from the left menu.
1. The "Practice Builder" page will appear showing all of the Development Blocks created.  In addition, it is possible to open an unsaved practice from a previous session.
2. Input the name of the Practice Session as well as the time of the session and objective.
3. You may assign yourself or any of the coaches listed when the app was configured for your team and sport (See Configuration)
4. Click on a Development Block and a subsequent page will appear listing the drills associated with that Block.
5. Update the sets, minutes and seconds.  The changed fields will update the total time for the practice session in the progress bar as well as the remaining minutes
6. When finished and you are satisfied with the Practice Session, you may then save the session and either export it to a PDF or print the session.

## Open, New and Duplicate

These options allow you to open an existing Practice Session, create a new one or duplicate the current practice session you have loaded in the app.

## Configuration

Click on the "Administration" button on the left side.  The Configuration page will appear.  Clicking on any of the buttons will produce:
* Drill Manager - this is where you will be able to create a drill and input all of the pertinent information needed.  There are no required fields.  You many also insert links into any of the appropriated fields to highlight them when a session is either exported to a PDF or printed.  If printed or exported to a PDF, it is possible to click on the highlight and bring up that link in a separate window.

* Configuration - the configuration page will appear.  Enter the name of your sport (e.g. Baseball, Football, Varsity Football, JV Soccer - up to 15 characters). You can also list any associate coaches which will the appear on the Practice Builder and you may assign any drills to them.

You will build the Block Development list which will be used to create a list of drills associated with that block.  Again, there are no required fields and you may treat the drill field with whatever you desire.  However, minutes and seconds must be whole integers.

* Database Maintenance - Click on this field to see the status of the database.  You will also be able to backup the database if desired

* Restore Database Backup - In case of accidental deletion or corruption of the database, you will be able to restore it from a saved one created from the "Database Maintenance" abover

* Create Drill Template - If you or one of your associates wish to enhance the current application, it is possible for them to use an Excel spreadsheet and filling in the cells according to the headings generated by the template

* Import Drill Spreadsheet - Using the template generated from the "Create Drill Tempilate", a spreadsheet may be imported to add to the current database.  Duplicated named drills will not be imported and shown in the log and alerted when the spreadsheet is attempted upload.

* Export Drill Spreadsheet - This option may be used to either backup a current drill database or given to another coach which can then be imported if they also have a version of the application.




## Reordering Development Blocks

1. Open **Administration** from the left sidebar.
2. Select **Configuration**.
3. Find the **Block List**.
4. Place the pointer over the three-dot handle (**•••**) beside the block you want to move.
5. Press and hold the left mouse button.
6. Drag the block onto the row where you want it positioned.
7. Release the mouse button. The new order is saved immediately.

The **Up** and **Down** buttons can also move a block one position at a time.
The first block cannot move farther up, and the last block cannot move farther down.

The configured order is used in the Practice Builder, Development Library, and Drill Manager.

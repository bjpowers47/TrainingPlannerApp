# Product Principles

## 1. The software supports the coach.

It never replaces the coach's judgment.

---

## 2. Progress is more important than perfection.

Track improvement over time rather than chasing arbitrary targets.

---

## 3. Optimize for the coach's workflow.

The interface should match how coaches naturally think and work.

---

## 4. Preserve history.

Archive instead of delete whenever possible.

---

## 5. Build for the next programmer.

Readable code is more valuable than clever code.
